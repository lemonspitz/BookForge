Book Forge 1.3 for Linux
========================

1. Install Calibre (free). The official installer is best:
     sudo -v && wget -nv -O- https://download.calibre-ebook.com/linux-installer.sh | sudo sh /dev/stdin
   Your distribution's calibre package also works if it includes Qt WebEngine (it does on Debian, Ubuntu and Fedora).
2. Unzip this folder somewhere it can stay, for example ~/Applications/Book Forge.
3. Run ./install.sh to add Book Forge to your applications menu (or start it with ./book-forge.sh).

For scanned PDFs (optional): install Tesseract with the languages you need, e.g.
     sudo apt install tesseract-ocr tesseract-ocr-ind tesseract-ocr-jpn
PDFs that already contain text don't need it.

Kindles connect over MTP. If yours doesn't show up, make sure no other program (a file manager, gvfs) has
mounted it, unplug it and plug it in again.
Your library is kept in ~/Documents/Book Forge Library, the same layout as the Mac app.
The Claude API key and email password go into your keyring (needs secret-tool, from libsecret-tools);
without it they are kept in ~/.config/book-forge, readable only by you.
