Book Forge 1.3 for Windows
==========================

1. Install Calibre (free) from https://calibre-ebook.com/download_windows
   Book Forge runs on Calibre's built-in Python and uses its e-reader drivers and converters.
2. Unzip this folder somewhere it can stay, for example Documents\Book Forge.
3. Double-click Install.cmd. Book Forge appears in the Start menu and on the desktop.
   (Or just double-click "Book Forge.cmd".)

For scanned PDFs (optional): install Tesseract OCR from https://github.com/UB-Mannheim/tesseract/wiki
and tick the Indonesian and Japanese languages in its installer. PDFs that already contain text don't need it.

Your library is kept in Documents\Book Forge Library, the same layout as the Mac app.
Close Calibre's own window while Book Forge talks to your Kindle: only one program can hold the connection.
Your Claude API key and email password are kept in Windows Credential Manager.
If something goes wrong, the log is in %LOCALAPPDATA%\Book Forge\Cache\book-forge.log
