Book Forge 1.1 for Windows
==========================

1. Unzip this folder somewhere it can stay, for example Documents\Book Forge.
2. Double-click Install.cmd to add Book Forge to the Start menu and the desktop
   (or just double-click "Book Forge.exe"). Windows may warn that the app is from an unknown publisher:
   choose More info > Run anyway.

Nothing else is needed for your library, the reader, PDF to EPUB, translation, and Kindle/Kobo sync over USB.

Optional:
- Calibre (calibre-ebook.com): only to turn EPUBs into Kindle books (so they appear in the Kindle's own
  library with covers) and to import Kindle-format books (AZW3, MOBI) as EPUB. A Kindle running KOReader opens
  EPUBs without it, and Email to Kindle converts them too.
- Tesseract OCR (github.com/UB-Mannheim/tesseract/wiki, with the languages your books are in): only for
  scanned PDFs.

Your library is kept in Documents\Book Forge Library, the same layout as the Mac app.
Your Claude API key and email password are kept in Windows Credential Manager.
If something goes wrong, the log is in %LOCALAPPDATA%\Book Forge\Cache\book-forge.log
